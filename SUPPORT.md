# Support

trust-cg v0.1.0 is a research preview maintained on a best-effort basis.

Use [GitHub Issues](https://github.com/alabsystems/trust-cg/issues) for build
problems, documentation questions, feature requests, and non-sensitive bugs.
Search existing issues first and include the trust-cg revision, Rust version,
host and target triples, optimization level, input format, relevant environment
controls, and the smallest reproducer available.

For suspected miscompilations, preserve the original input, actual output, and
independent oracle result. For sensitive vulnerabilities, follow
[`SECURITY.md`](SECURITY.md) instead of filing publicly.

There is no guaranteed response time, compatibility SLA, or long-term support
branch for the 0.x series.
