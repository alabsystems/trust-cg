# trust-cg

**Lower trust-ir. Emit native code. Inspect the evidence.**

A proof-oriented compiler backend in Rust targeting AArch64 and x86-64. trust-cg consumes TrustIr and emits native code while preserving inspectable evidence for the lowering it performed.

## Status

Public release in preparation, gated on [trust-ir](https://github.com/alabsystems/trust-ir).

This repository is the **public release tier** for `trust-cg`. Development happens in a
private repository; public snapshots are promoted here as reviewed releases tagged
`v<major>.<minor>.0`. See the publication engine's `VERSIONING.md` for the scheme.
